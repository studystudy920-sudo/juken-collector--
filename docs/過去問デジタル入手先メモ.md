# 大学入試 過去問のデジタル入手先メモ

大学受験の過去問を電子書籍・PDF・オンラインで入手する手段の整理。
（調査日: 2026-07-07 / 公開情報にもとづく整理であり法的助言ではない）

## ⭐ 特に押さえておく2サービス

### 旺文社「入試正解デジタル」（サブスク型）
- 全国 **200大学以上・10科目**（英・数・国・物・化・生・日本史・世界史・地理・政経）
- 有料プランで **最大11年分** 閲覧可能
- **無料登録（旺文社まなびID）で直近年度は閲覧可**
- 料金: 3か月 3,500円〜（6か月 6,600円 / 12か月 8,800円・税込、2026/7/30改定後）
- ※ 買い切りファイルではなく **Web閲覧型（サブスク）**
- URL: https://kakomon.obunsha.co.jp/

### 東進「大学入試問題過去問データベース」
- **無料**（要 東進WEB会員登録）
- **190大学以上**、大学によっては **約27年分** ＋ 共通テスト（2008〜）
- **印刷・PDF保存 可**
- ただし **詳しい解説は付かない**
- URL: https://www.toshin-kakomon.com/

## 電子書籍（買い切り）について
- **赤本（大学別 過去問題集）そのものの電子書籍版は基本的に存在しない**
  （教学社が方針として非電子化：書店維持・紙の体験重視・著作権処理の複雑さ）
- 参考書シリーズ「赤本プラス」は電子書籍化あり（BOOK☆WALKER等、1,650〜2,530円）※過去問集ではなく参考書

## 共通の制約（重要）
- **著作権処理で本文が削除される**：英語長文・国語などの第三者著作物は許諾が取れないと省略される
- **公開年数の制限**：公式は直近3年程度のみ
- **解説の有無**：無料サービスは解説なしが多い

## ⚠️ 収集・再配布の法的注意
- 設問の著作権は大学、引用文は元の著者/出版社に帰属
- 実際の試験での利用は著作権法36条でOKだが、**過去問集・過去問サイト等の二次利用は対象外**（事前許諾が必須）
- 無断のネット掲載は大学の複製権・公衆送信権、第三者著作物の著作権を侵害しうる
- → **個人利用（自分で見る・印刷する）に留めるのが安全**
