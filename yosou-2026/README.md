# 情報処理安全確保支援士（SC）試験 2026年 予想問題集

過去問（令和3〜7年）の出題傾向と最新セキュリティ動向の調査に基づいて作成した、2026年の年2回の試験に向けた予想問題集です。

> **注意**: 本問題集はAIが過去問傾向を分析して作成した**予想問題**であり、IPAの実際の試験問題ではありません。
> 2026年度（令和8年度）からSC試験はCBT方式に移行し、実施時期は「前期（2026年11月頃）」「後期（2027年2月頃）」の予定です（出題形式・合格基準は従来どおり）。

## 今年の予想の柱

1. **AIセキュリティ・LLM** — 「出る出る」と言われ続けて未出題の大本命。プロンプトインジェクション（直接/間接）、OWASP Top 10 for LLM、RAGの情報漏えい、AIエージェントの過剰な代理権限、MITRE ATLAS、敵対的サンプル、モデルインバージョン。
2. **MITRE ATT&CK** — 戦術/技術/手順（TTP）の体系、キルチェーンとの対比、SOCでの検知活用。午前IIの定義問題＋午後のインシデント対応シナリオ双方で狙われる。
3. **定番の進化形** — パスキー/FIDO2、OAuth 2.0＋PKCE、mTLS、ゼロトラスト（SASE/SSE）、DMARC、耐量子暗号（PQC）、ランサムウェア対応、サプライチェーン/SBOM。

## 作成プロセス（マルチエージェント）

3フェーズ・計15エージェントの並列ワークフローで作成:

1. **調査**（3エージェント並行）: 過去問傾向 / AIセキュリティ / 最新トピックをWeb調査
2. **作問**（6エージェント並行）: 6分野それぞれの専門作問エージェントが午前II・午後問題を作成
3. **監修**（6エージェント並行）: 技術監修エージェントが正解・解説の技術的誤りを検証・訂正
